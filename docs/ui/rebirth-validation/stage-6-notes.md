# Audit transversal — changements de ce cycle

1. États vides et erreurs défilent sous petites fenêtres et grandes polices.
2. Aperçu de partage défilable.
3. Confirmation de suppression défilable.
4. Actions Keep editing / Leave unsaved adaptables sur petites largeurs.
5. Réessayer reste visible sans pousser le message d’erreur hors écran.
6. Retour dans l’éditeur restaure position de défilement.
7. Champ titre conserve une cible tactile de 48 dp.
8. Date d’édition suit le locale après changement de configuration.
9. Recherche bas de page tronque proprement son indicatif.
10. Titres de sections exposent une annonce TalkBack unique et regroupée.
11. Barre à puce affiche le clavier après sélection du paragraphe.
12. Épinglage désactivé montre un état visuel désactivé.

Tests de fenêtres 360, 393, 412, 840 dp ajoutés, mais requièrent appareil pour s’exécuter. Aucun appareil, clavier réel, lecteur d’écran ou capture visuelle disponible pendant ce cycle.
