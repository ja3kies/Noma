# Éditeur — changements de ce cycle

1. Barre supérieure réduite à export et menu, en plus de Retour.
2. Barre d’outils Noma en bas, située au-dessus de l’IME.
3. Recherche dans le document déplacée dans cette barre.
4. Épinglage déplacé dans cette barre avec ses protections de sauvegarde.
5. Ajout/retrait d’une puce de texte sur le paragraphe courant, via l’autosave.
6. Action explicite pour masquer le clavier, visible lorsqu’il est ouvert.
7. Sélection et composition suivies par TextFieldValue ; sélection restaurable.
8. Changements de sélection sans écriture inutile dans le modèle.
9. Suppression de la barre permanente « enregistré » ; les états en cours et échoué restent visibles.
10. Insets du Scaffold consommés avant le contenu, évitant une seconde réservation IME.
11. Surface minimale d’écriture calculée sur la hauteur disponible.
12. Marges supérieure et inférieure d’écriture réduites.
13. Métadonnées masquées pendant la saisie avec clavier.
14. Capitalisation de phrases native sur titre et corps.

La puce est du texte brut. Ce n’est pas une checklist structurée. Aucun format de sauvegarde n’est modifié.
